# Frontend Integration Guide: Ideas & AI Features

This guide details the new API endpoints for managing Ideas and integrating AI-powered Product Documentation.

## **1. Ideas Management**

### **Get All Ideas**
*   **Endpoint**: `GET /api/ideas`
*   **Description**: Retrieves a list of all ideas for the current business.
*   **Response**:
    ```json
    {
      "success": true,
      "data": [
        {
          "id": "uuid",
          "businessId": "uuid",
          "userId": "uuid",
          "userName": "Creator Name",
          "title": "Idea Title",
          "description": "Idea Description",
          "status": "under_review",
          "createdAt": "timestamp",
          "updatedAt": "timestamp"
        }
      ]
    }
    ```

### **Create Idea**
*   **Endpoint**: `POST /api/ideas`
*   **Description**: Creates a new idea.
*   **Payload**:
    ```json
    {
      "title": "My New Idea",
      "description": "Detailed description of the idea."
    }
    ```
*   **Response**: Returns the created idea object.

### **Edit Idea**
*   **Endpoint**: `PUT /api/ideas/:id`
*   **Description**: Updates the title and description of an existing idea.
*   **Payload**:
    ```json
    {
      "title": "Updated Title",
      "description": "Updated description."
    }
    ```
*   **Response**: Returns the updated idea object.

### **Delete Idea**
*   **Endpoint**: `DELETE /api/ideas/:id`
*   **Description**: Deletes an idea and its associated product documentation.
*   **Response**:
    ```json
    {
      "success": true,
      "message": "Idea deleted successfully"
    }
    ```

### **Update Idea Status**
*   **Endpoint**: `PUT /api/ideas/:id/status`
*   **Description**: Updates the status of an idea (Admin/Manager only).
*   **Payload**:
    ```json
    {
      "status": "executed" // Options: "under_review", "executed", "rejected"
    }
    ```

## **2. AI-Powered Product Documentation**

### **Generate Documentation**
*   **Endpoint**: `POST /api/ideas/:ideaId/documentation`
*   **Description**: Uses AI to generate detailed product documentation based on the idea's title and description.
*   **Response**:
    ```json
    {
      "success": true,
      "data": {
        "id": "uuid",
        "idea_id": "uuid",
        "title": "Idea Title",
        "content": "Markdown formatted content generated by AI...",
        "created_at": "timestamp"
      }
    }
    ```

### **Get Documentation**
*   **Endpoint**: `GET /api/ideas/:ideaId/documentation`
*   **Description**: Retrieves all generated documentation for a specific idea.
*   **Response**: Returns an array of documentation objects.

### **Edit Documentation (with Logo Upload)**
*   **Endpoint**: `PUT /api/product-documentation/:id`
*   **Description**: Updates the content of the documentation and/or uploads a logo.
*   **Content-Type**: `multipart/form-data`
*   **Payload**:
    *   `content`: (String) Updated markdown content.
    *   `logo`: (File) Image file for the logo (png, jpg, etc.).
*   **Response**: Returns the updated documentation object, including the `logo_url`.

### **Regenerate Documentation**
*   **Endpoint**: `POST /api/product-documentation/:id/regenerate`
*   **Description**: Regenerates the documentation based on specific areas of concern.
*   **Payload**:
    ```json
    {
      "areasOfConcern": "Focus more on the monetization strategy and technical architecture."
    }
    ```
*   **Response**: Returns the updated documentation object with new content.

### **Delete Documentation**
*   **Endpoint**: `DELETE /api/product-documentation/:id`
*   **Description**: Deletes a specific product documentation record.
*   **Response**:
    ```json
    {
      "success": true,
      "message": "Documentation deleted"
    }
    ```

### **Download PDF**
*   **Endpoint**: `GET /api/product-documentation/:id/pdf`
*   **Description**: Downloads the documentation as a beautifully formatted PDF.
*   **Features**:
    *   Includes the uploaded logo (if any) in the header.
    *   Includes Business Name and Owner Name.
    *   Properly formatted headings and paragraphs.
*   **Response**: Binary PDF file stream.
